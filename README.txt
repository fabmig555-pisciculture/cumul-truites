CUMUL TRUITES - INSTALLATION iPHONE

Cette version est une application web installable (PWA), utilisable depuis un iPhone sans Mac.

1. Décompresser ce dossier sur le PC.
2. Héberger les 3 fichiers sur une adresse HTTPS (GitHub Pages est le plus simple).
3. Ouvrir l'adresse HTTPS dans Safari sur l'iPhone.
4. Partager > Ajouter à l'écran d'accueil.

La caméra lit les EAN-13 de ta balance, extrait le poids, cumule le poids et le nombre de pavés et calcule le montant TTC.
Prix par défaut : 12,60 €/kg TTC, modifiable.

Le lecteur de code-barres utilise une bibliothèque chargée depuis Internet : l'iPhone doit avoir Internet pendant le scan.
